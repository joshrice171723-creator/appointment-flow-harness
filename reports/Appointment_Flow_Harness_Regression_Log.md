# Appointment Flow harness regression log

This log records degradation observed in a build, a refactor, or the experiment itself. It identifies what to avoid when revising the harness and what a later run needs to verify. Two builds can differ even when they receive the same instructions. The evidence below identifies the observed result and how much of it the experiment can attribute to a harness change.

That identifies an inherited failure pattern. The V2.7.2.1.0 first checkpoint reproduced the outcome with a different lookup and the reviewed revision repaired it.
