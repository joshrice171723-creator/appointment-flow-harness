# Experiment evidence index

[README](../README.md) · [Dashboard](../dashboard/index.html#evidence) · [Paired downloads](../runs/README.md)

The tables cover the saved experiment files. The record can be incomplete for early runs. An interrupted launch and a package with no launch record have no final grade. Command receipts can record setup, tests, or cleanup. An exit code applies to that command.

The [machine-readable index](../dashboard/evidence.json) includes all rows from the published benchmark CSVs, recovered benchmark tables, and the recovered local run and command metadata. It includes repeated test summaries when the command log identifies them. The index omits raw agent logs and private assessment inputs.

## Read the measurements

| Measure | Meaning |
|---|---|
| Database statements | Commands the measured operation sent to PostgreSQL. The inclusive total can contain transaction commands. Counts do not measure how much data each command handled. |
| Rows returned to Rails | Rows in SQL read results. A count can return one row after scanning many. The plan shows the work behind that result. |
| Rails records loaded | Active Record objects Rails created. A scalar query can return values without creating model objects. |
| Rows affected | Rows the database reports as changed by writes. A batched write can affect many rows in one statement. |
| PMS JSON bytes | Bytes read from the source connection. This can grow even when the PMS statement count stays flat. |
| PostgreSQL buffers | Page accesses reported by the executed plan. A shared hit reuses a cached page. This metric counts accesses, including repeat accesses. |
| Elapsed milliseconds | Time the operation took in the saved run. Use a median only when the dataset labels it as a median. Compare timing under the same test conditions. |
| Response hash | A digest of the response body. Equal hashes mean the captured bodies matched byte for byte. |
| Agent grade and independent tests | The agent grade covers the stated rubric. Independent checks exercise their named fixtures and rules. A pass covers the recorded revision and the stated scope. |
